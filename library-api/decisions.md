# Exercise 3 - Task 5

## Module System

I will use **ES Modules (ESM)** for `library-api`.

I chose ESM because it is the standard module system used by modern JavaScript and it works directly with Node.js without needing a build tool. It also gives us features such as `import`/`export` and top-level `await`. Since the project is already configured with `"type": "module"`, I will keep the same module system throughout the next three weeks for consistency.
