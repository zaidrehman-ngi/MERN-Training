## BookCard

| Prop | Type | Required | Default | Purpose |
|---|---|---|---|---|
| `book` | object | Yes | — | Contains the book information displayed by the card. |
| `onSelect` | function | No | — | Called when the card is selected. |
| `variant` | `"default" \| "compact"` | No | `"default"` | Controls the presentation style of the card. |
